# ClassFlow（映像授業 視聴状況管理）PWA

**前提:** 完全無料 / 外部API・サーバー不使用 / GitHub Pages でデプロイ可能  
**方式:** 端末内の暗号化ストレージ + 暗号化ファイルのエクスポート/インポートで共有

---

## できること（v1.0）
- **講師**
  - クラスDBを端末内に暗号化保存（AES-GCM）
  - 講座（科目/ユニット）管理
  - 生徒追加 → **招待ファイル**（暗号化）を生成
  - 生徒から提出された **更新ファイル**（暗号化）を取り込み
  - 進捗サマリCSV出力、簡易分析（上位視聴分）
  - 暗号化クラスDBのバックアップ出力/復元
- **生徒**
  - 招待ファイルを取り込み、**自分の進捗のみ**解除・編集
  - 視聴分ログ、ユニット完了チェック
  - 講師へ提出する **更新ファイル**（暗号化）を出力

---

## セキュリティ設計（重要）
- 端末内の講師クラスDBは **講師パスフレーズ** で暗号化されます。
- 生徒の進捗レコードは **生徒ごとのデータ鍵（DEK）** で暗号化され、
  - 講師パスフレーズ（teacher wrap）
  - 生徒パスフレーズ（student wrap）
  の**どちらでも復号できる**ように「二重ラップ」されています。
- 共有はすべて **暗号化ファイル**（JSON）です。サーバー不要。

> ⚠️ 講師パスフレーズを忘れると復元できません。  
> ⚠️ iOS/Safari はストレージが消える場合があります。講師は定期バックアップ推奨。

---

## 使い方（講師）
1. アプリを開き「講師として利用」→ 初回セットアップ
2. 「講座」タブで講座/ユニットを作成
3. 「生徒」タブで生徒追加（推奨：本名ではなく生徒コード）
4. 生徒追加時に生成される `ClassFlow_invite_*.json` を生徒へ渡す
5. 生徒から `ClassFlow_update_*.json` を受け取り、「共有/バックアップ」タブで取り込み
6. 「共有/バックアップ」タブでクラスDBバックアップを定期的に保存

---

## 使い方（生徒）
1. アプリを開き「生徒として利用」→ 招待ファイルを取り込む
2. 先生から渡されたパスフレーズで解除
3. 視聴分を記録・完了チェック
4. 「提出」タブで更新ファイルを作成し先生へ送る
